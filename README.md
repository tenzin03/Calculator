# 🌌 Nebula Calculator

A creative glassmorphism calculator built with plain **HTML, CSS and JavaScript**.

## Features
- Responsive mobile-friendly UI
- Glassmorphism + neon visual design
- Basic arithmetic operations
- Percentage and sign toggle
- Keyboard support
- Calculation history
- No frameworks or dependencies

## Run
Open `index.html` in any modern browser.

## GitHub
Create a GitHub repository, upload `index.html`, `style.css`, and `script.js`, then replace the placeholder link below with your repository URL.
